Learning goal. Set up both optimization problems and identify when atom splitting makes a map impossible.

The two classical formulations ask the same physical question at different mathematical resolutions. Monge moves each source point to one destination; Kantorovich permits randomized destinations and thereby turns a nonlinear constraint into a convex feasible set.

Transport costs

Let \(c:X\times Y\to(-\infty,\infty]\) be a Borel cost. Unless stated otherwise, assume the cost is bounded below, so its integrals are defined without subtracting infinities. The value \(c(x,y)=+\infty\) may encode a forbidden movement. For existence results we usually assume that \(c\) is lower semicontinuous and bounded below, while duality requires additional integrability conditions.

Definition 2.1 (Transport costs). For a measurable map \(T:X\to Y\) satisfying \(T_\#\mu=\nu\), its Monge cost is \[ \mathcal C_M(T)=\int_X c(x,T(x))\,\mathrm{d}\mu(x). \] The Monge value is \[ M_c(\mu,\nu)=\inf_{T_\#\mu=\nu}\mathcal C_M(T), \] with value \(+\infty\) if no admissible map exists.

Definition 2.2 (Transport costs). The Kantorovich value is \[ K_c(\mu,\nu)=\inf_{\pi\in\Pi(\mu,\nu)} \int_{X\times Y}c(x,y)\,\mathrm{d}\pi(x,y). \] A minimizer is an optimal transport plan. If it has the form \((\operatorname{id},T)_\#\mu\), then \(T\) is an optimal transport map.

Kantorovich relaxation

Proposition 2.3 (Kantorovich relaxation). Every admissible Monge map induces an admissible Kantorovich plan with the same cost. Consequently, \[ K_c(\mu,\nu)\le M_c(\mu,\nu). \]

Proof. Given \(T_\#\mu=\nu\), let \(F(x)=(x,T(x))\) and \(\pi_T=F_\#\mu\). For Borel \(A\subset X,B\subset Y\), \[ \begin{aligned} \pi_T(A\times Y)&=\mu(F^{-1}(A\times Y))=\mu(A),\\ \pi_T(X\times B)&=\mu(F^{-1}(X\times B))=\mu(T^{-1}(B))=\nu(B). \end{aligned} \] Thus \(\pi_T\in\Pi(\mu,\nu)\). The change-of-variables identity yields, whenever the cost integral is defined (in particular for a cost bounded below), \[ K_c(\mu,\nu)\le\int_{X\times Y}c\,\mathrm{d}\pi_T =\int_X c\circ F\,\mathrm{d}\mu =\mathcal C_M(T). \] Taking the infimum over all admissible \(T\) gives \(K_c\le M_c\). If there is no such \(T\), then \(M_c=+\infty\) and the inequality still holds.

The inequality can be strict because the Monge feasible set may be empty. Even when maps exist, the relaxed problem is analytically better behaved: \(\Pi(\mu,\nu)\) is convex and weakly compact, while a weak limit of graph measures need not itself be concentrated on a graph.

Example 2.4 (Atomic obstruction). If \(\mu=\delta_0\) and \(\nu=\tfrac12(\delta_{-1}+\delta_1)\), then \(M_c(\mu,\nu)=+\infty\) for every finite cost because no map can split the atom at \(0\). The Kantorovich problem has the unique feasible plan \(\delta_0\otimes\nu\), with value \(\tfrac12c(0,-1)+\tfrac12c(0,1)\).

When transport maps exist

Theorem 2.5 (Measurable transport theorem). If \(X,Y\) are standard Borel spaces, \(\mu\) is nonatomic, and \(\nu\in\mathcal P(Y)\), then there exists a measurable \(T:X\to Y\) such that \(T_\#\mu=\nu\).

Proof using the standard-Borel representation theorem. We invoke the following probability theorem: there are a measurable \(U:X\to(0,1)\) and a Borel embedding \(j:Y\to[0,1]\) such that \[ U_\#\mu=\lambda_{(0,1)},\qquad B=j(Y)\text{ is Borel},\qquad j^{-1}:B\to Y\text{ is measurable}. \] Put \(\eta=j_\#\nu\), \(F(t)=\eta(( -\infty,t])\), and \(Q(u)=\inf\{t:F(t)\ge u\}\). Right-continuity of \(F\) gives \[ Q(u)\le t\ \Longleftrightarrow\ u\le F(t),\qquad \lambda\{u:Q(u)\le t\}=F(t). \] (The converse uses \(F(t+1/k)\ge u\) and then \(k\to\infty\).) Thus \(Q_\#\lambda=\eta\). In particular \(E=Q^{-1}(B)\) is Borel and \[ \lambda(E)=\eta(B)=\nu(Y)=1. \] Fix \(y_0\in Y\) and set \(q(u)=j^{-1}(Q(u))\) on \(E\), and \(q(u)=y_0\) elsewhere. For Borel \(A\subset Y\), \(j(A)\) is Borel and \[ \begin{aligned} \lambda(q^{-1}(A)) &=\lambda\{u\in E:Q(u)\in j(A)\}\\ &=\eta(j(A))=\nu(j^{-1}(j(A)))=\nu(A). \end{aligned} \] The exceptional set \(E^c\) has zero measure. Finally \(T=q\circ U\) is measurable and \[ \mu(T^{-1}(A)) =\mu(U^{-1}(q^{-1}(A))) =\lambda(q^{-1}(A))=\nu(A). \] Hence \(T_\#\mu=\nu\).

This theorem gives feasibility, not optimality. The central structural question is therefore: under what assumptions is an optimal Kantorovich plan concentrated on a graph? For quadratic cost and an absolutely continuous source, Brenier's theorem answers this by showing that the unique optimal plan is induced by the gradient of a convex function.

Three elementary models

Example 2.6 (Translation). If \(\nu=(x\mapsto x+a)_\#\mu\) on \(\mathbb R^d\), then \(T(x)=x+a\) is admissible. For \(c(x,y)=|x-y|^p\), every point travels distance \(|a|\), so the cost is \(|a|^p\). Jensen's inequality applied to any coupling gives \[ \int|x-y|^p\,\mathrm{d}\pi \ge\left|\int(x-y)\,\mathrm{d}\pi\right|^p =|a|^p, \] proving optimality when the first moments exist.

Example 2.7 (Dilation). If \(\mu\) is uniform on \([0,1]\), \(\nu\) is uniform on \([0,2]\), and \(c(x,y)=|x-y|^2\), then \(T(x)=2x\) is admissible. One-dimensional monotone rearrangement will show that it is the unique optimal map \(\mu\)-almost everywhere.

Example 2.8 (A finite assignment). For equal-weight empirical measures with distinct source locations \(\mu=n^{-1}\sum_i\delta_{x_i}\) and \(\nu=n^{-1}\sum_j\delta_{y_j}\), every permutation \(\sigma\) induces a map with cost \(n^{-1}\sum_i c(x_i,y_{\sigma(i)})\). Kantorovich plans are doubly stochastic matrices. The Birkhoff--von Neumann theorem implies that some optimal plan is a permutation plan, although uniqueness may fail.

Convexity gained by relaxation

The Kantorovich objective is linear in \(\pi\), and its feasible set is convex. This allows compactness arguments, linear-programming duality, perturbation analysis, and entropy regularization. None of these tools requires an optimizer to be deterministic. The later theory will first solve the relaxed problem and then use duality and convex geometry to decide whether the optimizer actually comes from a map.

Exercises

feasibility before optimality

  1. Exercise 2.1. For \(\mu=\delta_0\), \(\nu=(\delta_{-1}+\delta_1)/2\), and \(c=|x-y|^2\), find both optimal values.

    Hint

    Check whether a deterministic map can split a source atom before minimizing the cost.

    Solution

    The only plan has cost one. There is no admissible map, so the Monge value is \(+\infty\).

  2. Exercise 2.2. Compute the optimal quadratic cost from \(\operatorname{Unif}[0,1]\) to \(\operatorname{Unif}[a,a+1]\). Explain why your candidate is globally optimal.

    Hint

    Try a translation, then use the difference of the means to obtain a matching lower bound.

    Solution

    Translation gives cost \(a^2\). Every coupling has mean displacement \(a\), so Jensen gives the matching lower bound.
