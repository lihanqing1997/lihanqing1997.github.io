Learning goal. Turn a value approximation into a certified policy and establish a precise asynchronous convergence result.

Value convergence and stopping

Value iteration is \(V_{k+1}=TV_k\). The contraction theorem gives \[ \|V_k-V^*\|_\infty\le\gamma^k\|V_0-V^*\|_\infty,\qquad \|V_k-V^*\|_\infty\le\frac{\|V_{k+1}-V_k\|_\infty}{1-\gamma}. \] The residual is computable with one extra backup. With \(V_0=0\), the first bound is \(\gamma^kR_{\max}/(1-\gamma)\). For \(0<\gamma<1\), error at most \(\epsilon\) is guaranteed when \[ k\ge\frac{\log(R_{\max}/[(1-\gamma)\epsilon])}{-\log\gamma}, \] or immediately if the requested tolerance already exceeds the initial bound.

Extracting a good policy

Theorem 8.1 (greedy-policy loss). If \(\pi_V\) is greedy with respect to \(V\), then \[ \|V^*-V^{\pi_V}\|_\infty \le\frac{2\gamma}{1-\gamma}\|V-V^*\|_\infty \le\frac{2\gamma}{(1-\gamma)^2}\|TV-V\|_\infty. \]

Proof. Let \(e=\|V-V^*\|_\infty\) and \(L=\|V^*-V^{\pi_V}\|_\infty\). Since \(TV=T^{\pi_V}V\), \[ \begin{aligned} V^*-V^{\pi_V} &=TV^*-T^{\pi_V}V^{\pi_V}\\ &=(TV^*-TV)+(T^{\pi_V}V-T^{\pi_V}V^{\pi_V}). \end{aligned} \] Contraction and the triangle inequality imply \[ L\le\gamma e+\gamma\|V-V^{\pi_V}\|_\infty \le\gamma e+\gamma(e+L). \] Thus \((1-\gamma)L\le2\gamma e\). Substitute \(e\le\|TV-V\|_\infty/(1-\gamma)\). At \(\gamma=0\), immediate-reward greediness is already optimal and the loss is zero.

Asynchronous updates without delays

Theorem 8.2 (fair asynchronous iteration). Update one state \(i_k\) at each step: \[ V_{k+1}(i_k)=(TV_k)(i_k),\qquad V_{k+1}(s)=V_k(s)\quad(s\ne i_k). \] If every state is selected infinitely often, then \(V_k\to V^*\) in sup norm.

Proof. Put \(E_k=\|V_k-V^*\|_\infty\). The changed component satisfies \[ |V_{k+1}(i_k)-V^*(i_k)|\le\gamma E_k; \] all others retain their errors, so \(E_{k+1}\le E_k\). Set \(n_0=0\). Choose \(n_{j+1}>n_j\) so every state is updated at least once in \([n_j,n_{j+1})\). These finite times exist by infinite visitation and finiteness of the state set. Every update in that interval sees error at most \(E_{n_j}\), hence leaves its coordinate with error at most \(\gamma E_{n_j}\). Therefore \[ E_{n_{j+1}}\le\gamma E_{n_j}\le\gamma^{j+1}E_0. \] For all \(k\ge n_j\), \(E_k\le E_{n_j}\). Given \(\epsilon>0\), choose \(j\) with \(\gamma^jE_0<\epsilon\); then every \(k\ge n_j\) satisfies \(E_k<\epsilon\). No uniform update frequency is needed.

Gauss–Seidel sweeps use newly updated values and satisfy this theorem. Stale parallel reads require a separate delay assumption and proof; infinite updates alone do not control arbitrarily old information. The factors \((1-\gamma)^{-1}\) in the error bounds explain why high-discount problems need especially accurate backups.

Worked example 8.3 (propagating a delayed reward). Use the stay/go model with \(\gamma=0.9\). From \(V_0=0\), the greedy scores at \(s\) are \(1\) for stay and \(0\) for go. The first backup gives \(V_1=(1,2)\), whose scores are \(1.9\) and \(1.8\), still favoring stay. Next, \(V_2=(1.9,3.8)\), so \[ 1+0.9(1.9)=2.71<0.9(3.8)=3.42. \] Go now becomes greedy. Each sweep propagates continuation rewards one transition farther.

Exercises

  1. Exercise 8.1. At \(\gamma=0.9\), what residual tolerance guarantees greedy-policy loss at most \(0.1\) by this theorem?

    Hint

    Solve the greedy-policy residual certificate for the allowed residual.

    Solution

    Require \(2(0.9)\epsilon/(0.1)^2\le0.1\), so \(\epsilon\le1/1800\). This sufficient bound can be conservative when action gaps are large.

  2. Exercise 8.2. Explain failure if a state is never updated.

    Hint

    Use an absorbing state whose initial estimate is wrong and whose coordinate never changes.

    Solution

    Take two absorbing states with zero reward. Initialize the unvisited state's value at \(1\), although its true value is \(0\). Updating only the other state leaves this error unchanged forever.
