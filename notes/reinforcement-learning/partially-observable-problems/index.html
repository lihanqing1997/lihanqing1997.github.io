Learning goal. Construct the belief-state transition explicitly and prove the finite-horizon piecewise-linear value representation.

Beliefs as controlled sufficient statistics

Definition 23.1 (Observation model and belief update).

Let the hidden state space \(\mathcal S\), action space \(\mathcal A\), and observation alphabet \(\mathcal Y\) be finite. Use a joint kernel \(K_a(s',y\mid s)\) for next state and observation, with nonnegative entries summing to one for each \((s,a)\). Let the observed reward be a bounded function \(g(a,y)\), so \(r(s,a)=\sum_{s',y}K_a(s',y\mid s)g(a,y)\). The observation includes any reward information available to the agent. If a separate reward signal is informative, it must be included in the filtering update rather than silently ignored.

Before action \(A_t\), the available history is \(H_t=(Y_0,A_0,Y_1,\ldots,A_{t-1},Y_t)\), with a specified initial observation law. Define \(b_t(s)=\Pr(S_t=s\mid H_t)\). The policy uses only this observed history and independent randomization. For a candidate belief \(b\), define \[ p(y\mid b,a)=\sum_{s,s'}b(s)K_a(s',y\mid s),\qquad \tau(b,a,y)(s')= \frac{\sum_s b(s)K_a(s',y\mid s)}{p(y\mid b,a)} \] when the denominator is positive; choose any probability vector when it is zero.

Proof. The agent's randomized action is conditionally independent of the hidden state given its observed history. Therefore \[ \begin{aligned} \Pr(S_{t+1}=s',Y_{t+1}=y\mid H_t,A_t=a) &=\sum_s\Pr(S_t=s\mid H_t,A_t=a)K_a(s',y\mid s)\\ &=\sum_s b_t(s)K_a(s',y\mid s). \end{aligned} \] Summing over \(s'\) gives \(p(y\mid b_t,a)\); division gives Bayes' formula for \(b_{t+1}=\tau(b_t,a,y)\) on every positive-probability observation. Thus \[ \Pr(b_{t+1}\in B\mid H_t,A_t=a) =\sum_y p(y\mid b_t,a)\mathbf1_{\{\tau(b_t,a,y)\in B\}}, \quad \mathbb E[R_{t+1}\mid H_t,A_t=a]=\sum_s b_t(s)r(s,a). \] Both quantities depend on the history only through \(b_t\). Values assigned at zero-probability observations are multiplied by zero and have no effect. This proves the controlled Markov property of the belief process.

Dynamic programming on the probability simplex

Let \(V_n(b)\) be the optimal expected discounted reward for the next \(n\) steps, with \(V_0=0\). Finite-horizon conditioning gives \[ V_{n+1}(b)=\max_a\left\{\sum_s b(s)r(s,a)+ \gamma\sum_y p(y\mid b,a)V_n(\tau(b,a,y))\right\}. \] For bounded functions on the simplex, this operator is a \(\gamma\)-contraction: the continuation weights are nonnegative and sum to one, and the difference of maxima is bounded by the maximum difference. Thus for \(\gamma<1\) it has a unique bounded fixed point, and \(\|V_\infty-V_n\|_\infty\le R_{\max}\gamma^n/(1-\gamma)\). The finite-horizon policies achieve the truncated values, and the same uniform tail bound identifies the fixed point with the supremum over infinite observation-history policies.

Theorem 23.2 (finite-horizon alpha vectors). For each finite \(n\), there is a finite set \(\Gamma_n\subset\mathbb R^{|\mathcal S|}\) such that \[ V_n(b)=\max_{\alpha\in\Gamma_n}b^\top\alpha. \] In particular \(V_n\) is piecewise linear and convex in the belief.

Proof. Take \(\Gamma_0=\{0\}\). Suppose the representation holds at \(n\). For any \(a,y\) with positive observation probability, \[ p(y\mid b,a)V_n(\tau(b,a,y)) =\max_{\alpha_y\in\Gamma_n} \sum_{s,s'}b(s)K_a(s',y\mid s)\alpha_y(s'). \] The equality also holds at zero probability because all summands \(b(s)K_a(s',y\mid s)\) are then zero. Since the choice of continuation vector may depend on the observed \(y\), each term can be maximized independently. For every action \(a\) and tuple \((\alpha_y)_{y\in\mathcal Y}\in\Gamma_n^{|\mathcal Y|}\), define \[ \alpha^{a,(\alpha_y)}(s)=r(s,a)+ \gamma\sum_{y,s'}K_a(s',y\mid s)\alpha_y(s'). \] Substitution into the Bellman formula yields \[ V_{n+1}(b)= \max_{a,(\alpha_y)}\sum_s b(s)\alpha^{a,(\alpha_y)}(s). \] The collection of these vectors is finite, completing the induction. For \(u\in[0,1]\), \[ \max_\alpha[ub^\top\alpha+(1-u)c^\top\alpha] \le u\max_\alpha b^\top\alpha+(1-u)\max_\alpha c^\top\alpha, \] which proves convexity. Uniform convergence preserves this inequality for \(V_\infty\), but need not leave a finite alpha-vector representation at infinite horizon.

The belief space is continuous even when the hidden state space is finite. Alpha-vector sets can grow combinatorially; point-based planning approximates their effect on selected reachable beliefs. A recurrent neural state is not automatically a sufficient statistic: it must retain the distinctions needed to predict controlled future rewards and observations.

Worked example 23.3 (the value of observing). The hidden state is \(L\) or \(R\), with belief \(b(L)=p\). A final guess gives reward one if correct, zero otherwise, so \[ V_{\rm guess}(p)=\max\{p,1-p\}, \qquad \Gamma=\{(1,0),(0,1)\}. \] At an earlier decision with exactly one future guess, compare “observe,” which costs \(c\) and perfectly reveals the state, with “wait,” which gives no information and no reward. Their values are \[ Q_{\rm observe}(p)=-c+\gamma,\qquad Q_{\rm wait}(p)=\gamma\max\{p,1-p\}. \] Observing is preferred precisely when \(c<\gamma\min\{p,1-p\}\). Information has the greatest value near the ambiguous belief \(p=1/2\).

Exercises

  1. Exercise 23.1. A static hidden bit has prior probability \(1/2\) and a sensor reports the correct bit with probability \(0.8\). Compute the posterior after observing \(L\).

    Hint

    Write the two joint probabilities of the hidden state and observed sensor report before normalizing.

    Solution

    Bayes gives \(b'(L)=(0.5\cdot0.8)/(0.5\cdot0.8+0.5\cdot0.2)=0.8\). The posterior probability of \(R\) is \(0.2\).

  2. Exercise 23.2. Why is belief value convex for reward maximization, while analogous cost-minimization diagrams are often concave?

    Hint

    Each fixed policy tree gives a linear function of the initial belief; examine its upper or lower envelope.

    Solution

    A fixed finite policy tree has value linear in the initial belief. Maximizing over trees gives an upper envelope of linear functions, hence convexity. Minimizing their costs gives a lower envelope, hence concavity.
