Derive the Gibbs policy and soft Bellman operator, including the reference-measure convention and the zero-temperature limit.

Relative entropy fixes the convention

For each state choose a reference distribution \(\mu(a\mid s)>0\), and let \(\tau>0\). Define \[ \mathrm{KL}(p\|\mu)=\sum_a p_a\log\frac{p_a}{\mu_a}, \qquad 0\log0=0. \] We maximize discounted reward minus \(\tau\mathrm{KL}(\pi(\cdot\mid s)\|\mu(\cdot\mid s))\). For uniform \(\mu\) on \(m\) actions, \(-\mathrm{KL}(\pi\|\mu)=H(\pi)-\log m\). Thus adding Shannon entropy instead changes values by \(\tau\log m/(1-\gamma)\) when every state has \(m\) actions; it does not change the optimal policy in that case.

Theorem (finite Gibbs variational formula). For \(q\in\mathbb R^m\), \[ \max_{p\in\Delta_m}\{p^\top q-\tau\mathrm{KL}(p\|\mu)\} =\tau\log\sum_a\mu_a e^{q_a/\tau},\qquad p_a^*=\frac{\mu_a e^{q_a/\tau}}{\sum_b\mu_b e^{q_b/\tau}}. \] The maximizer is unique.

Proof. Let \(Z=\sum_a\mu_a e^{q_a/\tau}>0\). Then \(\log(p_a^*/\mu_a)=q_a/\tau-\log Z\), so for every \(p\), \[ p^\top q-\tau\mathrm{KL}(p\|\mu) =\tau\log Z-\tau\mathrm{KL}(p\|p^*). \] For \(p_a>0\), \(-\log(p_a^*/p_a)\ge1-p_a^*/p_a\). Multiplication by \(p_a\) and summation give \[ \mathrm{KL}(p\|p^*)\ge \sum_{a:p_a>0}(p_a-p_a^*)=\sum_{a:p_a=0}p_a^*\ge0. \] Since \(p^*\) is strictly positive, equality requires full support and equality in the logarithm inequality at every action, hence \(p=p^*\). Substitution gives the result.

Soft dynamic programming

Set \[ (T_\tau V)(s)=\tau\log\sum_a\mu(a\mid s) \exp\!\left(\frac{r(s,a)+\gamma PV(s,a)}{\tau}\right), \] \[ T_{\pi,\tau}V=r_\pi-\tau\,\mathrm{KL}(\pi\|\mu)+\gamma P_\pi V. \] The variational formula gives \(T_\tau V=\max_\pi T_{\pi,\tau}V\), state by state.

Proof. If \(\|V-W\|_\infty\le e\), each action score differs by at most \(\gamma e\). Therefore \[ e^{-\gamma e/\tau}\sum_a\mu_a e^{q_W(a)/\tau} \le\sum_a\mu_a e^{q_V(a)/\tau} \le e^{\gamma e/\tau}\sum_a\mu_a e^{q_W(a)/\tau}. \] Taking \(\tau\log\) proves \(\|T_\tau V-T_\tau W\|_\infty\le\gamma e\). Hence \(T_\tau\) has a unique fixed point \(V_\tau\). Let \(\pi_\tau\) be its Gibbs maximizer. Then \(T_{\pi_\tau,\tau}V_\tau=T_\tau V_\tau=V_\tau\), so policy evaluation identifies \(V_\tau=V_\tau^{\pi_\tau}\). For any possibly history-dependent action distribution \(p_t(\cdot\mid H_t)\), the variational inequality gives \[ V_\tau(S_t)\ge \mathbb E[R_{t+1}+\gamma V_\tau(S_{t+1})\mid H_t] -\tau\mathrm{KL}(p_t(\cdot\mid H_t)\|\mu(\cdot\mid S_t)). \] Iterating conditional expectations for \(H\) steps yields a bound on the regularized partial return plus \(\gamma^H\mathbb E V_\tau(S_H)\). The terminal term tends to zero because \(V_\tau\) is bounded. Also, with \(\mu_{\min}=\min_{s,a}\mu(a\mid s)>0\), \[ 0\le\mathrm{KL}(p\|\mu)\le\log(1/\mu_{\min}), \] so the regularized return tails are uniformly bounded by \(\gamma^H[R_{\max}+\tau\log(1/\mu_{\min})]/(1-\gamma)\). Passing to the limit proves optimality among these policies, with equality for \(\pi_\tau\).

Soft policy iteration evaluates \(V_\tau^\pi\), then takes its Gibbs policy \(\pi'\). Since \(T_{\pi',\tau}V_\tau^\pi=T_\tau V_\tau^\pi\ge T_{\pi,\tau}V_\tau^\pi=V_\tau^\pi\), monotonicity and repeated evaluation imply \(V_\tau^{\pi'}\ge V_\tau^\pi\). The KL gap above quantifies the improvement at each state.

Proposition (zero-temperature value limit). \[ 0\le V^*(s)-V_\tau(s) \le\frac{\tau\log(1/\mu_{\min})}{1-\gamma}. \]

Proof. The penalty is nonnegative, so every regularized policy value is at most its unregularized value, and \(V_\tau\le V^*\). Let \(\pi^*\) be a deterministic unregularized optimal policy. Its per-state penalty is \(\tau\log[1/\mu(\pi^*(s)\mid s)]\le\tau\log(1/\mu_{\min})\). Thus \[ V_\tau\ge V_\tau^{\pi^*} \ge V^{\pi^*}-\sum_{t=0}^\infty\gamma^t\tau\log(1/\mu_{\min})\,\mathbf1 =V^*-\frac{\tau\log(1/\mu_{\min})}{1-\gamma}\mathbf1 . \] The bound is uniform in states; consequently \(V_\tau\to V^*\) uniformly as \(\tau\downarrow0\).

Soft actor-critic combines entropy-regularized targets with approximate critics and a restricted stochastic actor. In continuous action spaces the sum becomes an integral; a reference measure and finiteness of the partition function must be specified. A Gaussian actor, sampled gradients, and neural critic errors introduce approximation issues beyond the exact finite-action contraction theorem.

Worked example (Gibbs probabilities and value). One state has rewards \(0,\log3\), uniform reference \((1/2,1/2)\), \(\tau=1\), and \(\gamma=1/2\). The common continuation factor cancels from the Gibbs probabilities: \[ \pi_\tau=(1/4,3/4),\qquad V_\tau=\tfrac12V_\tau+\log[(1+3)/2]=\tfrac12V_\tau+\log2. \] Hence \(V_\tau=2\log2\), whereas \(V^*=2\log3\). The gap \(2\log(3/2)\) is smaller than the bound \(2\log2\).

Exercises

  1. Show that for a fixed score vector \(q\), Gibbs probability concentrates on its maximizers as \(\tau\downarrow0\).

    Hint and solution

    Write \(M=\max_a q_a\). For a suboptimal action, \(p_\tau(a)=\mu_a e^{-(M-q_a)/\tau}/\sum_b\mu_b e^{-(M-q_b)/\tau}\to0\). On the maximizing set the limiting probabilities are proportional to \(\mu_a\). This statement fixes \(q\); a temperature-dependent score needs separate analysis.

  2. What is the exact optimization loss from using \(p\) instead of the Gibbs policy for a fixed \(q\)?

    Hint and solution

    The variational identity gives \(\tau\mathrm{KL}(p\|p^*)\). This measures a one-state policy update error, not by itself the total return loss after visitation distributions change.
