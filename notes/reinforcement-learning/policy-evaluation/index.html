Learning goal. Evaluate a fixed policy from a known model or independent simulated episodes, separating sampling error from return truncation.

Exact and iterative evaluation

For a stationary policy in a finite discounted MDP, \[ (I-\gamma P_\pi)V^\pi=r_\pi. \] A direct linear solve obtains the value without explicitly computing a matrix inverse. Alternatively, iterate \(V_{k+1}=T^\pi V_k\).

Theorem 6.1 (evaluation error). \[ V_k-V^\pi=\gamma^kP_\pi^k(V_0-V^\pi),\qquad \|V_k-V^\pi\|_\infty\le\gamma^k\|V_0-V^\pi\|_\infty. \] At any iterate, \(\|V_k-V^\pi\|_\infty\le\|T^\pi V_k-V_k\|_\infty/(1-\gamma)\).

Proof. Subtract the fixed-point equation from one update: \[ V_{k+1}-V^\pi =(r_\pi+\gamma P_\pi V_k)-(r_\pi+\gamma P_\pi V^\pi) =\gamma P_\pi(V_k-V^\pi). \] Induction yields the exact error identity. Since \(\|P_\pi^k\|_{\infty\to\infty}\le1\), taking norms gives the bound. For the residual, \[ V^\pi-V_k=(I-\gamma P_\pi)^{-1}(T^\pi V_k-V_k). \] Its norm is at most \(\sum_{t\ge0}\gamma^t\|T^\pi V_k-V_k\|_\infty\), which equals the stated certificate.

Monte Carlo with an explicit sampling law

Suppose the environment can be restarted independently at state \(s\). Generate independent episodes under the same policy, with full discounted returns \(G_i\). Then \[ \widehat V_n(s)=\frac1n\sum_{i=1}^nG_i,\quad \mathbb E G_i=V^\pi(s),\quad |G_i|\le B:=\frac{R_{\max}}{1-\gamma}. \] The strong law gives \(\widehat V_n(s)\to V^\pi(s)\) almost surely. Returns from overlapping visits along one trajectory are generally dependent; this independent-episode statement does not cover them.

Proposition 6.2 (truncation and confidence). Use only \(H\) rewards of each episode and set \(\widehat V_{n,H}=n^{-1}\sum_iG_i^{(H)}\). For \(0<\delta<1\), with probability at least \(1-\delta\), \[ |\widehat V_{n,H}(s)-V^\pi(s)| \le B\gamma^H+B\sqrt{\frac{2\log(2/\delta)}n}. \]

Proof. Let \(m_H=\mathbb E_s^\pi G^{(H)}\). The deterministic tail bound gives \[ |m_H-V^\pi(s)|\le\mathbb E|G^{(H)}-G|\le B\gamma^H. \] The independent variables \(G_i^{(H)}\) lie in \([-B,B]\), an interval of length \(2B\). Hoeffding's inequality gives \[ \mathbb P(|\widehat V_{n,H}-m_H|>u) \le2\exp\left(-\frac{2nu^2}{(2B)^2}\right). \] Set \(u=B\sqrt{2\log(2/\delta)/n}\). On the complementary event, \[ |\widehat V_{n,H}-V^\pi(s)| \le|\widehat V_{n,H}-m_H|+|m_H-V^\pi(s)|\le u+B\gamma^H. \] For all states simultaneously, allocate failure probability \(\delta/|\mathsf S|\) to each state and take a union bound.

What one trajectory changes

A continuing trajectory may support consistency through an ergodic theorem, but its sample size is not a count of independent returns. Finite-sample bounds need explicit mixing or martingale arguments. TD below handles dependence by conditioning on history. Least-squares TD appears after function approximation is defined.

For a stationary scalar sequence \((Y_t)\) with finite second moments, expansion gives \[ \operatorname{Var}\left(\frac1n\sum_{t=1}^nY_t\right) =\frac{\operatorname{Var}(Y_0)}n+ \frac2{n^2}\sum_{k=1}^{n-1}(n-k)\operatorname{Cov}(Y_0,Y_k). \] Indeed, expand the variance as \(n^{-2}\sum_{i,j}\operatorname{Cov}(Y_i,Y_j)\): there are \(n\) diagonal pairs and \(2(n-k)\) ordered pairs at lag \(k\). Dropping the covariance terms requires a reason such as independence.

Worked example 6.3 (a computable stopping decision). Let \(\gamma=1/2\), \(P_\pi=\begin{pmatrix}1/2&1/2\\0&1\end{pmatrix}\), \(r_\pi=(1,2)^\top\), and \(V_0=0\). Then \[ V_1=(1,2)^\top,\quad V_2=(7/4,3)^\top,\quad T^\pi V_2=(35/16,7/2)^\top. \] The residual is \((7/16,1/2)^\top\), giving error certificate \(1\). The exact value \((8/3,4)^\top\) has error \(\max\{11/12,1\}=1\), so the certificate is attained.

Exercises

  1. Exercise 6.1. If rewards lie in \([0,1]\), improve the sampling constant.

    Hint

    Use the length of the smaller interval containing each return in Hoeffding’s inequality.

    Solution

    Returns lie in \([0,B]\), an interval of length \(B\). Hoeffding gives \(B\sqrt{\log(2/\delta)/(2n)}\), half the previous radius. Truncation is unchanged.

  2. Exercise 6.2. For \(\gamma=1/2,R_{\max}=1\), choose \(H,n\) making the stated bound at most \(0.1\) with confidence \(0.95\), allocating half to each error.

    Hint

    Allocate the tolerance between the geometric truncation term and the sampling term, then solve each inequality.

    Solution

    Here \(B=2\). Require \(2(1/2)^H\le0.05\), so \(H=6\). Require \(2\sqrt{2\log40/n}\le0.05\), so \(n\ge3200\log40\); \(n=11805\) suffices.
