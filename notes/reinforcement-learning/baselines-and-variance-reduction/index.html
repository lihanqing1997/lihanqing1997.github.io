Learning goal. Separate preservation of the gradient mean from reduction of its variance, and compute the bias introduced by an approximate critic.

State baselines and their optimal value

At a fixed state \(s\), let \(A\sim\pi_\theta(\cdot\mid s)\), \(Z=\nabla\log\pi_\theta(A\mid s)\), and let \(Y\) be an integrable return target with \(\mathbb E[Y\mid s,A]=Q^\pi(s,A)\). Assume \(\mathbb E[\|Z\|^2Y^2\mid s]<\infty\). The variance criterion below is the trace of the conditional covariance, \(\mathbb E\|X-\mathbb E X\|^2\).

Proposition 15.1 (optimal scalar state baseline). For every finite \(b=b(s)\), \(\mathbb E[Z(Y-b)\mid s]=\mathbb E[ZY\mid s]\). If \(c(s)=\mathbb E[\|Z\|^2\mid s]>0\), the variance-minimizing baseline is \[ b_*(s)=\frac{\mathbb E[\|Z\|^2Y\mid s]}{\mathbb E[\|Z\|^2\mid s]}. \] If \(c(s)=0\), then \(Z=0\) almost surely and every baseline is equivalent.

Proof. Normalization of the policy gives \(\mathbb E[Z\mid s]=\sum_a\nabla\pi_\theta(a\mid s)=0\). The mean is therefore independent of \(b\). Subtracting its squared norm from the second moment does not change the minimizer. Expand \[ \mathbb E[\|Z\|^2(Y-b)^2\mid s] =\mathbb E[\|Z\|^2Y^2\mid s] -2b\,\mathbb E[\|Z\|^2Y\mid s]+b^2c(s). \] Completing the square gives \(M(b)=M(b_*)+c(s)(b-b_*)^2\). This proves both optimality and the exact variance penalty for a non-optimal baseline.

In general \(b_*\ne V^\pi(s)\): the optimal baseline weights actions by squared score length. A baseline fitted using the very same action/return can also become action dependent. To preserve the displayed conditional argument, treat the fitted baseline as fixed using independent data, or condition on training data independent of the current action sample. An action-dependent \(b(s,a)\) requires the correction \[ Z(Y-b(s,A))+\sum_a\pi_\theta(a\mid s)z_\theta(s,a)b(s,a), \] whose expectation is \(\mathbb E[ZY\mid s]\); simply subtracting \(Zb(s,A)\) is generally biased.

Reward to go: unbiased does not mean universally lower variance

The policy-gradient proof removes past rewards using \(\mathbb E[Z_t\mid H_t]=0\). This establishes equality of expectations. It is not, by itself, a conditional-expectation projection of the whole gradient estimator, so a universal variance inequality does not follow.

Worked example 15.2 (a variance counterexample). Take two time steps. The first action is fixed, \(R_1=-\gamma\); the second action is Bernoulli with probability \(p=\sigma(\theta)\), but \(R_2=1\) for both actions. The total discounted return is identically zero. At \(p=1/2\), the second-action score \(Z=A-1/2\) has variance \(1/4\). Thus \[ \widehat g_{\rm full}=Z(R_1+\gamma R_2)=0,\qquad \widehat g_{\rm to\ go}=\gamma ZR_2=\gamma Z, \] \[ \mathbb E\widehat g_{\rm full}=\mathbb E\widehat g_{\rm to\ go}=0, \qquad \operatorname{Var}(\widehat g_{\rm to\ go})=\gamma^2/4> \operatorname{Var}(\widehat g_{\rm full})=0 \] when \(\gamma>0\). Removing irrelevant random terms often helps in practice, but covariance with retained terms matters.

Generalized advantage estimation

Let \(\widetilde V=V^\pi+e\), \(\|e\|_\infty\le\varepsilon\), and \(0\le\lambda\le1\). Along an on-policy trajectory set \[ \delta_t^{\widetilde V}=R_{t+1}+\gamma\widetilde V(S_{t+1})-\widetilde V(S_t), \qquad \widehat A_t^\lambda=\sum_{\ell=0}^\infty(\gamma\lambda)^\ell \delta_{t+\ell}^{\widetilde V}. \] Bounded rewards and values make this series absolutely convergent, with a deterministic summable bound. This permits conditional expectation term by term.

Proposition 15.3 (exact conditional GAE bias). For \(\gamma<1\), \[ \mathbb E[\widehat A_t^\lambda\mid S_t=s,A_t=a] =A^\pi(s,a)-e(s)+ \gamma(1-\lambda)\sum_{j=1}^\infty(\gamma\lambda)^{j-1} \mathbb E[e(S_{t+j})\mid s,a]. \] In particular the target is conditionally unbiased for the advantage if \(e=0\).

Proof. For the exact value, \(\mathbb E[\delta_t^{V^\pi}\mid s,a]=A^\pi(s,a)\). If \(\ell\ge1\), the tower property through the history before action \(A_{t+\ell}\) gives \[ \mathbb E[\delta_{t+\ell}^{V^\pi}\mid H_{t+\ell}] =(T_\pi V^\pi-V^\pi)(S_{t+\ell})=0. \] Also \(\delta_{t+\ell}^{\widetilde V}-\delta_{t+\ell}^{V^\pi} =\gamma e(S_{t+\ell+1})-e(S_{t+\ell})\). For a finite sum through \(n-1\), reindexing yields \[ \begin{aligned} \sum_{\ell=0}^{n-1}(\gamma\lambda)^\ell [\gamma e(S_{t+\ell+1})-e(S_{t+\ell})] &=-e(S_t)+\gamma(1-\lambda) \sum_{j=1}^{n-1}(\gamma\lambda)^{j-1}e(S_{t+j})\\ &\quad+\gamma(\gamma\lambda)^{n-1}e(S_{t+n}). \end{aligned} \] The last term has magnitude at most \(\gamma\varepsilon(\gamma\lambda)^{n-1}\to0\). The middle series is absolutely bounded by \(\gamma(1-\lambda)\varepsilon/(1-\gamma\lambda)\). Taking conditional expectations and then \(n\to\infty\) proves the formula (the case \(\gamma\lambda=0\) follows directly from the first TD error).

The term \(-e(s)\) is a state baseline and disappears after multiplying by the policy score and averaging actions. If \(\|z\|\le L\), the bias of the normalized occupancy gradient is therefore at most \[ \frac{L\varepsilon}{1-\gamma}\, \frac{\gamma(1-\lambda)}{1-\gamma\lambda}. \] At \(\lambda=1\), an infinite-horizon return minus any fixed state baseline preserves the gradient mean. Finite rollout truncation leaves a terminal term and must be analyzed separately; \(\lambda=1\) does not remove that error.

Worked example 15.4 (the best baseline is not the value). In a one-step Bernoulli bandit with reward \(Y=A\), let \(p=1/4\). The logit score is \(Z=A-p\), so \[ V=p=\tfrac14,\qquad b_*= \frac{p(1-p)^2}{p(1-p)^2+(1-p)p^2}=1-p=\tfrac34. \] With \(b=b_*\), both action outcomes give \(Z(Y-b)=p(1-p)=3/16\). The gradient estimator has zero variance; using the value baseline does not attain this.

Exercises

  1. Exercise 15.1. For a single TD error (\(\lambda=0\)), identify the conditional advantage bias and the policy-gradient bias.

    Hint

    Set the trace parameter to zero in the bias identity and use the zero-mean score.

    Solution

    The advantage bias is \(\gamma\mathbb E[e(S_{t+1})\mid s,a]-e(s)\). After score averaging only \(\gamma\mathbb E[z_t e(S_{t+1})]\) remains. The normalized gradient bias is bounded by \(\gamma L\varepsilon/(1-\gamma)\).

  2. Exercise 15.2. If all actions have the same score norm at a state, show that \(b_*=V^\pi(s)\).

    Hint

    Cancel the common squared-score factor in the optimal-baseline ratio.

    Solution

    When \(\|Z\|^2=c>0\) almost surely, the common factor cancels: \(b_*=\mathbb E[Y\mid s]=\sum_a\pi(a\mid s)Q^\pi(s,a)=V^\pi(s)\).
