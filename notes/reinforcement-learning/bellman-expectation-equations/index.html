Derive policy evaluation as a linear equation, prove the resolvent representation, and control the tails behind reward shaping.

The policy Bellman equation

Retain the finite discounted model and use column vectors for values and rewards. For a fixed stationary policy, define \[ T^\pi V=r_\pi+\gamma P_\pi V. \] The one-step identities in the previous chapter give \(V^\pi=T^\pi V^\pi\). We also write \(P_aV(s):=\sum_{s'}P(s'\mid s,a)V(s')\) for a single action backup. The operator is affine, not linear unless \(r_\pi=0\).

Theorem (resolvent and uniqueness). \[ (I-\gamma P_\pi)^{-1}=\sum_{t=0}^{\infty}\gamma^tP_\pi^t, \qquad V^\pi=\sum_{t=0}^{\infty}\gamma^tP_\pi^tr_\pi. \] The matrix series converges in the operator norm induced by \(\|\cdot\|_\infty\), and the value series converges uniformly.

Proof. For any vector \(z\), \[ |(P_\pi z)(s)|\le\sum_{s'}P_\pi(s,s')|z(s')| \le\|z\|_\infty,\quad\text{so }\|P_\pi^t\|_{\infty\to\infty}\le1. \] Let \(B_n=\sum_{t=0}^{n-1}\gamma^tP_\pi^t\). For \(m>n\), \[ \|B_m-B_n\|_{\infty\to\infty} \le\sum_{t=n}^{m-1}\gamma^t\le\frac{\gamma^n}{1-\gamma}. \] Thus \(B_n\to B\) in matrix norm. Finite telescoping gives both identities \[ (I-\gamma P_\pi)B_n=B_n(I-\gamma P_\pi) =I-\gamma^nP_\pi^n. \] The remainder norm is at most \(\gamma^n\to0\). Continuity of matrix multiplication implies \((I-\gamma P_\pi)B=B(I-\gamma P_\pi)=I\). Hence the inverse exists. Moreover, \[ \left\|V^\pi-B_nr_\pi\right\|_\infty \le\frac{\gamma^n\|r_\pi\|_\infty}{1-\gamma}. \] Finally, the Markov property gives \((P_\pi^tr_\pi)(s)=\mathbb E_s^\pi r(S_t,A_t)\), so this series agrees with the expected return already defined. Invertibility also proves uniqueness of the Bellman solution.

Action values and a lifted transition matrix

Index vectors by admissible state-action pairs and set \[ P_Q^\pi((s,a),(s',a'))=P(s'\mid s,a)\pi(a'\mid s'). \] Every row sums to one. The same calculation therefore gives \[ Q^\pi=r+\gamma P_Q^\pi Q^\pi, \qquad Q^\pi=(I-\gamma P_Q^\pi)^{-1}r. \] In operator notation, \((\Pi_\pi Q)(s)=\sum_a\pi(a\mid s)Q(s,a)\), so \(V^\pi=\Pi_\pi Q^\pi\) and \(Q^\pi=r+\gamma PV^\pi\). The two equations describe the same prediction problem at different points in the action cycle.

Order, subsolutions, and supersolutions

Proposition. If \(U\le T^\pi U\), then \(U\le V^\pi\). If \(U\ge T^\pi U\), then \(U\ge V^\pi\). Increasing \(r_\pi\) while keeping \(P_\pi\) fixed increases the value.

Proof. Let \(e=T^\pi U-U\). Subtract \((I-\gamma P_\pi)U=r_\pi-e\) from the equation for \(V^\pi\): \[ V^\pi-U=(I-\gamma P_\pi)^{-1}e =\sum_{t\ge0}\gamma^tP_\pi^te. \] If \(e\ge0\), every term is nonnegative; if \(e\le0\), every term is nonpositive. For rewards \(\tilde r_\pi\ge r_\pi\), \[ \widetilde V^\pi-V^\pi =\sum_{t\ge0}\gamma^tP_\pi^t(\tilde r_\pi-r_\pi)\ge0. \] All series converge in sup norm by the previous theorem.

Potential-based reward shaping

Proposition. Let \(\Phi:\mathsf S\to\mathbb R\) be bounded and define the shaped reward \[ R'_{t+1}=R_{t+1}+\gamma\Phi(S_{t+1})-\Phi(S_t). \] Then \(V'^\pi(s)=V^\pi(s)-\Phi(s)\) and \(Q'^\pi(s,a)=Q^\pi(s,a)-\Phi(s)\); advantages and action rankings are unchanged.

Proof. For every path and finite \(n\), \[ \begin{aligned} \sum_{t=0}^{n-1}\gamma^t(R'_{t+1}-R_{t+1}) &=\sum_{t=0}^{n-1}\gamma^{t+1}\Phi(S_{t+1}) -\sum_{t=0}^{n-1}\gamma^t\Phi(S_t)\\ &=-\Phi(S_0)+\gamma^n\Phi(S_n). \end{aligned} \] The last term is bounded in absolute value by \(\gamma^n\|\Phi\|_\infty\to0\), both pathwise and in \(L^1\). Taking limits and then expectations under a specified initial state or forced first action gives \[ V'^\pi=V^\pi-\Phi,\qquad Q'^\pi(s,a)=Q^\pi(s,a)-\Phi(s). \] Subtract the two identities to get \(A'^\pi=A^\pi\). The subtraction in \(Q\) is independent of the action, so it preserves each greedy set.

Worked example (solve the system and check the series). Take \(\gamma=1/2\), \(P_\pi=\begin{pmatrix}1/2&1/2\\0&1\end{pmatrix}\), and \(r_\pi=(1,2)^\top\). Then \[ V_2=2+\tfrac12V_2=4,\quad V_1=1+\tfrac14V_1+\tfrac14V_2, \quad V_1=\tfrac83. \] Starting from state 1, the expected reward at time \(t\) is \(2-2^{-t}\). Hence \[ \sum_{t\ge0}2^{-t}(2-2^{-t})=4-\frac4{3}=\frac83, \] which independently verifies the matrix solution.

Exercises

  1. For the example, shape with \(\Phi=(1,0)^\top\). Compute the new mean reward and value.

    Hint and solution

    \(r'_\pi=r_\pi+\gamma P_\pi\Phi-\Phi=(1/4,2)^\top\). Thus \(V'^\pi=(5/3,4)^\top=V^\pi-\Phi\).

  2. If \(\|\tilde r_\pi-r_\pi\|_\infty\le\epsilon\) with the same transition matrix, bound the value change.

    Hint and solution

    Use the resolvent: \(\|\widetilde V^\pi-V^\pi\|_\infty\le\sum_{t\ge0}\gamma^t\epsilon=\epsilon/(1-\gamma)\). Equality is possible for a constant reward shift.
