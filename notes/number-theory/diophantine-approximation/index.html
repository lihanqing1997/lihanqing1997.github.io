Diophantine approximation asks how closely irrational numbers can be approximated by rationals and how arithmetic structure limits that accuracy. Continued fractions give optimal one-dimensional approximants; geometry of numbers and transcendence methods extend the theory.

Dirichlet's approximation theorem

Theorem (Dirichlet). For every \(\alpha\in\mathbb R\) and \(Q\ge1\), there exist integers \(p,q\) with \[ 1\le q\le Q,\qquad \left|\alpha-\frac pq\right|<\frac1{qQ}. \] If \(\alpha\) is irrational, infinitely many \(p/q\) satisfy \[ \left|\alpha-\frac pq\right|<\frac1{q^2}. \]

Proof. Place the \(Q+1\) fractional parts \[ 0,\{\alpha\},\ldots,\{Q\alpha\} \] into \(Q\) intervals of length \(1/Q\). Two lie in the same interval, so for \(q=|j-i|\) there is an integer \(p\) with \(|q\alpha-p|<1/Q\). Irrationality prevents finitely many denominators from accounting for all \(Q\).

Badly approximable and algebraic numbers

Theorem (Hurwitz). Every irrational \(\alpha\) has infinitely many approximants satisfying \[ \left|\alpha-\frac pq\right|<\frac1{\sqrt5\,q^2}. \] The constant \(1/\sqrt5\) is optimal.

A number is badly approximable if \[ \left|\alpha-\frac pq\right|>\frac c{q^2} \] for some \(c>0\) and all \(p,q\). This is equivalent to bounded continued fraction coefficients. Quadratic irrationals are badly approximable.

Theorem (Roth). If \(\alpha\) is algebraic irrational, then for every \(\varepsilon>0\), \[ \left|\alpha-\frac pq\right|<\frac1{q^{2+\varepsilon}} \] has only finitely many rational solutions.

Dirichlet shows exponent \(2\) is universal; Roth shows algebraic irrationals cannot improve it by any fixed power. Liouville's earlier, weaker bound already produced the first explicit transcendental numbers.
